# Cargas Eletromagnéticas para Alunos Cegos

Modelo tátil de cargas elétricas positivas e negativas, desenvolvido para apoiar o ensino de Eletrostática a estudantes cegos ou com deficiência visual.

O material permite explorar, por meio do tato, as características das cargas elétricas e a representação das linhas de campo elétrico, contribuindo para a compreensão de conceitos fundamentais da Física de forma acessível e inclusiva.

O projeto pode ser reproduzido por meio de fabricação digital, utilizando os arquivos disponibilizados neste repositório.

## Arquivos disponíveis

- `.svg` – arquivo vetorial escalável, indicado para edição gráfica e utilização em diferentes aplicações digitais.
- `.dxf` – arquivo vetorial compatível com softwares CAD e aplicações de fabricação digital, incluindo corte a laser.
- `.wcvr` – arquivo compatível com o software AutoLaser, utilizado nas cortadoras a laser Delta CNC.
- `.jpeg` – fotografia do modelo após a fabricação.

## Aplicações educacionais

- Ensino de Eletrostática e cargas elétricas.
- Exploração tátil das cargas positivas e negativas.
- Representação e identificação das linhas de campo elétrico.
- Produção de recursos didáticos acessíveis para estudantes cegos ou com deficiência visual.

## Fabricação

O modelo pode ser produzido por corte a laser, utilizando materiais como MDF ou acrílico, conforme as características do projeto e os recursos disponíveis.

## Acessibilidade e compartilhamento

Este projeto busca contribuir para a construção de práticas pedagógicas inclusivas, utilizando a fabricação digital para desenvolver recursos didáticos táteis que ampliem as possibilidades de aprendizagem em Física.

Os arquivos são disponibilizados para facilitar a reprodução, a adaptação e o compartilhamento do material por professores, estudantes e laboratórios maker.
